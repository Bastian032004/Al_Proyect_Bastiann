# Actividad Formativa: GitHub Copilot - INACAP

## Objetivo
Explorar las tendencias emergentes en inteligencia artificial utilizando **GitHub Copilot** como herramienta práctica para el desarrollo de un sistema de recomendaciones en Python.

## Pasos Realizados

1. **Configuración de GitHub y Repositorio:**
   - Se ingresó a GitHub y se creó el repositorio `AI_Proyect_Bastiann` inicializado con un archivo `README.md`.
2. **Clonación Local en Visual Studio Code:**
   - Se abrió la terminal integrada en Visual Studio Code y se clonó el repositorio localmente utilizando el comando `git clone`.
3. **Desarrollo con GitHub Copilot (`recommendation_system.py`):**
   - Se creó el archivo `recommendation_system.py` y se generó la estructura de un modelo de aprendizaje automático utilizando las librerías `numpy`, `pandas` y `scikit-learn` (`KNeighborsClassifier`) para entrenar un clasificador y recomendar productos.
4. **Control de Versiones (Git):**
   - Se registraron los cambios locales mediante `git add .`, `git commit` y se subieron al repositorio remoto en GitHub con `git push`.
